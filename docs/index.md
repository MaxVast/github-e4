# Documentation du projet github-e4

Bienvenue dans la documentation de **github-e4**, l'application web React de la
4ème année d'ENIGMA School, 2026-2027.

Cette documentation a quatre objectifs :

- faciliter l'arrivée d'un nouveau collaborateur ;
- centraliser les informations et les projets en cours ;
- donner accès à la documentation officielle des technologies utilisées ;
- faciliter la collaboration entre les différents collaborateurs.
