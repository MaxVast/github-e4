# Configuration

Cette page décrit la configuration de github-e4.

## Fichiers de configuration

| Fichier | Rôle |
|---------|------|
| `vite.config.js` | Configuration de Vite (build, serveur de développement) |
| `eslint.config.js` | Règles d'analyse statique du code |
| `package.json` | Dépendances et scripts npm |

Documentation officielle :

- [Configurer Vite](https://vite.dev/config/)
- [Configurer ESLint](https://eslint.org/docs/latest/use/configure/)
